# 🦅 Granna - Controle Financeiro Pessoal

![Version](https://img.shields.io/badge/version-1.1.6-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

Aplicação desktop para controle financeiro pessoal. Oferece uma interface moderna e intuitiva para gerenciar transações, categorias, metas financeiras e lembretes.

## 🚀 Como Instalar e Executar

Para utilizar o Granna, siga os passos abaixo:

1. **Baixe o arquivo compactado (`.zip`)** do aplicativo.
2. **Descompacte o arquivo**:
   - Clique com o botão direito sobre o arquivo `.zip` baixado.
   - Selecione a opção **"Extrair Tudo..."** (no Windows) ou equivalente no seu sistema operacional.
   - Escolha uma pasta de sua preferência para salvar os arquivos extraídos.
   
   > [!IMPORTANT]
   > **Atenção:** É necessário descompactar todos os arquivos contidos no `.zip` antes de executar. 

3. **Inicie o aplicativo**:
   - Abra a pasta onde você descompactou os arquivos.
   - Dê um duplo clique no executável **`Granna.exe`** (no Windows) ou no arquivo correspondente à sua plataforma (macOS/Linux).

## ✨ Funcionalidades

### 📊 Dashboard
- Visualização consolidada das suas finanças.
- Gráficos interativos de receitas e despesas.
- Alertas automáticos de limites de gastos excedidos.
- Acompanhamento do progresso de suas metas financeiras.
- Lembretes diários.

### 💰 Gestão de Transações
- Registro simplificado de receitas e despesas.
- Categorização de transações.
- Filtros e busca avançada para facilitar a localização de registros.
- Histórico completo de todas as suas movimentações financeiras.

### 🏷️ Categorias
- Criação e gerenciamento de categorias personalizadas.
- Segmentação por tipo (receita ou despesa).
- Personalização de cores para melhor organização visual.
- Definição de metas de orçamento por categoria.

### 🎯 Metas Financeiras
- Estabelecimento de objetivos financeiros vinculados a categorias.
- Acompanhamento do progresso em tempo real baseado em suas transações.

### 📈 Estatísticas
- Análise detalhada dos seus hábitos de consumo.
- Gráficos e relatórios visuais intuitivos.

### ⚠️ Limites de Gastos
- Definição de limites mensais de gastos por categoria.
- Alertas e controle de orçamento integrados.

### 📅 Agendamentos e Lembretes
- Criação de lembretes e agendamentos de transações recorrentes.
- Notificações de contas a vencer.
